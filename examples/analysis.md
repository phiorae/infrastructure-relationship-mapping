# Учебная аналитическая записка
Дата подготовки: 2026-11-13. Все данные синтетические.

**Вопрос:** какие домены разделяют ресурс в пересекающиеся интервалы наблюдений?
**Ответ:** portal.lab.test и mail.lab.test связаны IP (D01, D02) и fingerprint
(C01, C02) в интервале 2024-01-05 — 2024-01-10. Уверенность в вычислении
пересечения высокая; уверенность в общем операторе не установлена.

CDN-сосед cdn.partner.test образует две дополнительные IP-связи на 5–6 января
(D04 вместе с D01 / D02). Это намеренный пример альтернативного объяснения:
shared hosting может дать такой же граф без общего владельца.
archive.lab.test (D03) делит IP только в феврале; временных связей нет.

**Следующие проверки, если это собственный стенд:** сопоставить разрешённые
журналы выдачи сертификатов, историю конфигурации и инвентаризацию владельцев.
Не расширять scope на остальные домены хостинга автоматически.
Этот набор не позволяет устанавливать кампанию, угрозу или реального оператора.
